# Tá no Plano?

Comparativo cidadão dos planos de governo de 2026 — [presidência](https://ta-no-plano.github.io/) e [governo de Pernambuco](https://ta-no-plano.github.io/governadores/).

Os PDFs foram coletados no [DivulgaCandContas](https://divulgacandcontas.tse.jus.br) do TSE. Cada selo aponta para o trecho e a página do documento. Os resumos foram montados com apoio de IAs, como o Gemini.
