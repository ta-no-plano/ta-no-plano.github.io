# Tá no Plano?

Comparativo cidadão dos planos de governo de 2026 — [presidência](https://ta-no-plano.github.io/) e [governo de Pernambuco](https://ta-no-plano.github.io/governadores/).

Os PDFs foram coletados no [DivulgaCandContas](https://divulgacandcontas.tse.jus.br) do TSE. Cada selo aponta para o trecho e a página do documento. Os resumos foram montados com apoio de IAs, como o Gemini.

## Aparecer no Google

O site já tem título, descrição, página canônica, `robots.txt`, `sitemap.xml` e dados estruturados. Depois de publicar no GitHub Pages:

1. Abra o [Google Search Console](https://search.google.com/search-console)
2. Adicione a propriedade `https://ta-no-plano.github.io/`
3. Envie o mapa do site: `https://ta-no-plano.github.io/sitemap.xml`

O Google não mostra o site na hora: a primeira indexação costuma levar alguns dias. As visitas das duas páginas vão para o [Google Analytics](https://analytics.google.com).
